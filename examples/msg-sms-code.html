msg-sms-code 插件示例 · 短信验证码识别

插件名以 msg 开头 → 只订阅 new_msg（完整消息），从消息正文里识别短信验证码并调用页面全局 sendMsg(code) 自动发送。本页可离线演示验证码提取算法，点下方按钮即可看到识别结果。

本页加载方式

<script src="static/js/danmu.js?appName=你的应用名&channelCode=你的通道码&plugins=msg-sms-code,panel&danMu=1&hideIcon=1&hideDialog=1"></script>

与 msg-dialog 二选一，两者都写 settings.newMsgCallback，同时加载会互相覆盖。当前插件有两类场景使用：

  • 在弹幕中使用：可以去掉 plugins 里的 panel（plugins只需传 msg-sms-code）；需要在全局定义 window.sendMsg(code) 模拟发送弹幕或者在init({danMuMock:1}) 传入，否则只会在 console 控制台打印验证码。
  • 在推送窗口中使用：请去掉 hideDialog=1，会自动打开一个对话框，识别到的验证码会自动发送到通道，无需操作即可发送验证码到通道，任何监听通道的客户端都可以收到验证码。

本演示页加载线上 danmu.js，点下方按钮会真实推送一条消息；要体验完整链路，请到书签挂件页拖将“短信验证码识别”拖到书签栏，右上角选择提醒打开推送窗口可自动识别短信验证码。

提取算法（与插件内置逻辑一致，可单独复制）

/**
 * 从短信正文提取验证码，识别不到返回 ""
 */
function extractSmsCode(text) {
    if (text == null) return "";
    // 关键词按长度降序，优先匹配更具体的词组
    var KEYWORDS = /(?:短信验证码|验证码为|验证码是|验证码|校验码|动态码|动态密码|随机码|口令|verification\s*code|passcode|otp|code)/gi;
    // 先剥离 HTML 标签与颜色值，避免 <font color=#0465d2> 里的 0465 被误抓
    var clean = String(text)
        .replace(/<[^>]*>/g, "")
        .replace(/#[0-9a-fA-F]{3,8}\b/g, "")
        .replace(/&nbsp;/g, " ")
        .replace(/&amp;/g, "&");
    function isValid(num) {
        if (!num || num.length < 4 || num.length > 8) return false;
        if (/^1[3-9]\d{9}$/.test(num)) return false; // 手机号
        if (/^(?:19|20)\d{2}$/.test(num)) return false; // 年份
        return true;
    }
    // 1) 关键词后 40 字符内第一个合法数字
    var m;
    KEYWORDS.lastIndex = 0;
    while ((m = KEYWORDS.exec(clean)) !== null) {
        var after = clean.substring(m.index + m[0].length, m.index + m[0].length + 40);
        var found = after.match(/\d+/);
        if (found && isValid(found[0])) return found[0];
    }
    // 2) 兜底：正文中第一个独立的 4-6 位数字
    var all = /(?:\D|^)(\d+)(?:\D|$)/g, a;
    while ((a = all.exec(clean)) !== null) {
        if (isValid(a[1])) return a[1];
    }
    return "";
}

识别规则

步骤规则
清洗去掉 HTML 标签和 #颜色值，避免高亮颜色里的数字被误当成验证码。
关键词定位短信验证码 / 验证码为 / 验证码是 / 验证码 / 校验码 / 动态码 / 动态密码 / 口令 / otp / code 等，在关键词后 40 字符内取第一个 4–8 位独立数字。
排除干扰手机号（1[3-9] 开头 11 位）与年份（19xx / 20xx）不认为是验证码。
兜底没有关键词时，取正文中第一个合法的 4–6 位独立数字。
防回环按消息 ID 与已发送的验证码双重去重，避免自己发出去的验证码被广播回来后再次识别、无限循环。
