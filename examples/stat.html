stat 插件示例 · 访问统计

加载 plugins=stat 后，页面每次加载上报一条 head=visit，任意元素被点击再上报一条 head=click。click 的 body 是点击描述（能定位到网页哪个部分被点，不是整段 HTML），通道后台的「访问统计看板」据此看 PV/UV 与点击热点。

本页加载方式（演示 autoInit=0 + 自定义 settings）

加载中… WebsitePusher.init({ appName: "统计示例", channelCode: "你的通道码", danMu: 0, // 只统计，不渲染弹幕 hideDialog: 1, plugins: "stat", statHead: "visit", // 访问记录类型，默认 visit statClick: 1 // 0=不上报点击 });

autoInit=0 时 danmu.js 只加载依赖，初始化由业务方自己做，这样才能传自定义 settings。

操作

点击演示区（点下面任意元素都会上报一条 click）

点我：普通 div 元素
点我：a 标签（不上报跳转）

点击上报走捕获阶段，宿主代码里 stopPropagation() 也拦不住；组件自身 UI 的点击会自动跳过，不会把自己的界面操作刷进统计。

上报的 body 形如 body > div.wrap > div.click-demo > button "点我" @ 49.7%,47.7%；点在页面空白处则是 body @ 99.1%,86.9%。

参数默认说明
