关于这个Markdown转HTML工具

本地处理 · 无需上传 · 离线可用

Markdown转HTML工具把学习资料做成一个能统计、能赚钱的网页文件：把笔记转成网页后，随时可以看到这份资料被多少人打开过——哪怕你把它放进压缩包、通过网盘分享给别人，打开次数一样统计得到；还可以在网页里加入动态广告，把正在浏览资料的人变成收入（夸克网盘分享链接、京东、淘宝客双十一活动链接等都能放）。全程在你自己的电脑上完成，文件不会上传到任何服务器。

能做什么

  • 统计打开次数：生成的网页会自动记录被打开的次数，压缩包、网盘分享的也一样算，随时知道资料火不火、最近有没有人看。
  • 加入动态广告：网页里能嵌入广告，别人打开时自动展示，通过夸克网盘分享链接、京东、淘宝客双十一活动链接等赚取佣金。
  • 识别与更换设置：上传之前生成的网页，能自动认出里面已有的通道码；填新的下载即替换，不想留也可以移除。
  • 纯本地：生成、修改全部在自己电脑上完成，文件不上传，网站上也不留副本。

怎么用（三步）

  1. 上传：把 markdown 或 html 文件拖进来，或点击选择（单次 1 个）。
  2. 设置通道：「加通道统计」面板填上你的通道码，点「添加通道码并下载」；「提取内嵌通道码」面板会显示识别到的通道码。不填也能直接下载。
  3. 下载：markdown 生成 原文件名.html；带通道码的生成 原文件名-带通道码.html。

不填通道码时：markdown 生成普通网页；上传的 html 会生成移除原通道码的版本。

常见问题

这个工具能做什么？

把 markdown 文件转成离线 html（可填上 32 位通道码，让页面带上该通道的弹幕）；同时能从已生成的 html 里识别、替换或移除通道码。全部在你自己的浏览器里完成。

手头的资料是 PDF，不是 markdown，怎么办？

先用 PDF转html 把 PDF 转成离线 HTML（同样是浏览器里完成的纯前端工具），再把转出来的 html 传回本页填上通道码。之后有人下载打开就是一条访问记录，官网绑定飞书、钉钉、企业微信、邮箱后手机上实时收到访问提醒；离线包不用部署服务器，读者打开页面时联网就能持续给他推广告图 + 链接（plugins=ad，例如双十一活动页），点击跳转就是收入变现。

需要上传文件吗？会不会泄露？

不需要。文件用浏览器本地读取，Markdown 转换、通道码替换全部在当前标签页内完成，服务器上不存文件、没有日志、也不用注册账号。关掉页面就什么都不剩。

通道码是什么？

通道码是一封传话（聚合消息推送平台）的推送通道标识，32 位长度字符串（如 3db15cb9ff360873027019296797c796），在各通道中全局唯一。每个通道由一个通道码标识，无论日后更换聊天工具或接入方式，代码都不需要重写。通道码到一封传话官网注册后免费获取，生成的 html 会加载 danmu.js 的脚本，打开页面时需联网才能实时接收该通道的弹幕与消息。

一封传话是什么？官网在哪里？

一封传话是面向开发者和团队的聚合消息推送平台：一次 HTTP 调用或一行网页 JS，即可把消息同时送达企业微信、钉钉、飞书、邮件、Bark、Telegram、Discord 和自定义 Webhook。除推送外还内置网站弹幕（一行 JS 为任意网站加上弹幕，支持点赞交互、回调过滤与 AI 自动生成弹幕）、网站访问统计（把 danmu.js 带 plugins=stat 参数粘进任意页面，即可获得浏览量、访客数、来源渠道、设备分布等访问统计看板，注重隐私、不使用 Cookie）、广告（plugins=ad）默认停留30秒，可以修改自己新建通道码的停留时长。详细介绍与在线体验请访问官网首页：https://push.phprm.com/index.html。

上传的 html 里已有通道码，会被改动吗？

输入新通道码并下载时，原有通道码会被替换；不输入通道码直接下载时，会生成移除通道码的版本。除此之外文件的其他内容原样保留。

一次能处理多大的文件？

单次上传 1 个文件，markdown 或 html 均可（.md / .markdown / .html / .htm），单个不超过 10MB。这是浏览器内存与响应时间给的余量，不是格式限制。
