danmu 插件示例

当前示例包含访问统计、异常汇报、广告推送插件，可以在 官网 添加飞书、钉钉、企业微信、邮件，把异常和访问记录推送到你的手机上，还可以使用 markdown转html 将你的学习资料转化为可推送广告的离线HTML文件收入变现。

运行方式

下面几种打开方式都可以，任选一种：

  • web 服务器（推荐）：把 danmu 目录当站点根或子目录，访问 /examples/；
  • 静态站点服务器（如 npx serve .）：在仓库根目录启动后访问 /examples/；
  • 本地双击（file://）：例如你辛苦整理的离线文档资料同样能接入弹幕、统计和广告，见 markdown转html；
  • 单独分发某个 html 时，同样也可以统计打开人数、访问趋势以及推送广告，见 offline.html。

公共参数（写在 danmu.js 的 src 查询串上）

参数说明
appName应用名，用于统计；不传则不自动 init（配合 autoInit=0）。
channelCode通道码；不传则按当前网址自动认领。
danMu1=渲染弹幕；0=不渲染（仍做推送/统计；加载了 ad 插件时照常展示广告位）。
plugins要加载的插件，英文逗号分隔，如 stat、panel、stat,ad。默认不加载插件。
hideDialog1=不自动弹出对话窗口。
hideIcon1=不显示右下角入口图标（只想留广告位/面板时用）。
autoInit0=只加载依赖不初始化，之后监听 websitePusherReady 自行调用 WebsitePusher.init()（本目录的 stat / axios-report / vue-report 示例就是这样）。

autoInit=0 时 danmu.js 仅加载依赖资源，不执行初始化。依赖加载完成后会触发 websitePusherReady 事件并调用 window.onWebsitePusherReady 来配置更多自定义参数，参见 首页文档。

插件开发

组件按 plugins=名字 加载 plugins/名字.js；插件文件加载时调用 WebsitePusher.registerPlugin(名字, run) 注册，脚本 onload 后由组件执行 run(settings)。一个自定义插件就是一个 js 文件加一次注册。

1. 新建 plugins/mynote.js

(function () {
    if (typeof WebsitePusher === "undefined" || !WebsitePusher.registerPlugin) {
        return; // 组件还没加载，先放弃
    }
    WebsitePusher.registerPlugin("mynote", function (settings) {
        // settings 是 init() / 脚本地址传进来的全部参数，所有插件共用
        console.log("mynote 已启动，通道码=" + settings.channelCode);
        // 上报一条自定义消息，通道后台「推送记录」里能看到 head=mynote
        WebsitePusher.pushTrigger("mynote", "hello 自定义插件");
    });
})();

2. 加载插件

在脚本地址里写插件名，多个用英文逗号分隔；用 init() 时则写 plugins: "mynote"。

<script src="static/js/danmu.js?appName=你的应用名&channelCode=你的通道码&plugins=mynote"></script>

3. 想接管消息，就设置消息闸门

闸门返回 true 表示这条消息由插件处理，组件不再把它渲染成弹幕（ad 插件就是这样把广告画到右下角的）：

var origin = settings.danMuMessageCallback; // 先留住原有闸门
settings.danMuMessageCallback = function (message) {
    if (message.head === "mynote") {
        console.log("收到 mynote 消息", message);
        return true; // 我处理了，不渲染弹幕
    }
    return typeof origin === "function" ? origin.call(settings, message) : false;
};

4. 调试与发布

  • 插件里的异常会被组件捕获，不影响弹幕/统计主流程，调试看浏览器控制台；
  • 上报统一用 WebsitePusher.pushTrigger(head, body)，写完可在通道后台「推送记录」里确认；
  • 发布：如果使用你自己部署的 danmu.js，把文件放到 danmu.js 同级的 plugins/（线上为 static/customer/js/plugins/），文件名必须与插件名一致，改完记得强刷缓存；
  • 插件目录默认固定，确实要换只能在 init() 里传 pluginsSite（脚本地址不支持）。

示例页的公共处理

  • 把 WebsitePusher.pushTrigger 包一层，把 visit/click 等上报打到页面下方的「现场日志」，方便确认插件在工作；
  • 日志同时显示组件是否就绪、通道码是否认领成功、上报是否成功；
  • 纯 HTML + 原生 JS，不依赖框架，可整段复制下面的引入代码。
<script src="static/js/danmu.js?appName=你的应用名&channelCode=你的通道码&danMu=1&plugins=stat,panel"></script>

GET 请求触发推送

不想写前端、只想推一条消息时，直接请求下面这个地址即可（返回 code=0 表示成功）。参数说明见 ad.html。

https://www.phprm.com/services/push/trigger/你的通道码?head=广告&avatar=https://ws.phprm.com/static/demo/images/ad-demo.svg&url=https://push.phprm.com/&hold=30

复制此链接到浏览器地址栏粘贴访问同样可以触发推送。
