vue-report 插件示例 · Vue 异常上报

加载 plugins=vue-report 后，Vue 的异常与开发环境告警会上报一条 head=vue，在通道管理里面新增飞书、钉钉、企业微信、邮件推送通道。

没能从 CDN 加载 Vue，下面用内置的极简模拟器演示：它同样会走 Vue.createApp，只是 prop 类型校验的告警由示例直接调用 config.warnHandler 模拟。

本页加载方式（autoInit=0 + 自定义 settings）

加载中… WebsitePusher.init({ appName: "vue 上报示例", channelCode: "你的通道码", hideDialog: 1, plugins: "vue-report", vueReportMax: 10, // 本页最多上报条数，默认 10 vueReportWarn: 1 // 0=不上报警告，只报 errorHandler });

Vue2 接管全局 Vue.config；Vue3/4 包装 Vue.createApp，所以要在插件接管之后再 createApp（本页按钮每次点击都新建 app）。

可选 settings

参数默认说明
vueReportMax10本页最多上报条数；<=0 表示不上报。达到上限后只 console.warn。
vueReportWarn10=不接管 warnHandler，只上报真正的异常。

同一异常本页只报一次；body 超长会按 stack → info → message 的顺序瘦身，尽量保持合法 JSON；插件不写 Cookie/localStorage。
